# PETRO-STOCK-Enterprise-Petroleum-Management
PETRO-STOCK is a web-based petroleum management system designed to streamline oil production monitoring, depot inventory management, petroleum distribution, commercial billing, and operational reporting in South Sudan.

The system provides a centralized dashboard for monitoring petroleum operations, tracking storage tank levels, recording daily oil production, managing truck dispatches, generating waybills, and monitoring sales and revenue. It also includes interactive charts, inventory alerts, role-based access controls, and exportable reports to support operational visibility and decision-making.

Built with HTML, CSS, JavaScript, Bootstrap 5, and Chart.js, PETRO-STOCK features a responsive interface with dark and light themes and local storage for retaining application data in the browser.

Key Features

Dashboard & Analytics: Displays production statistics, inventory levels, fleet activity, and revenue summaries.

Oil Production Management: Records and searches daily production data.

Inventory Management: Monitors depot storage capacity, tank levels, and low-stock or overflow alerts.

Logistics & Distribution: Manages truck dispatch records and generates printable waybills.

Commercial Billing: Tracks invoices, sales records, and USD/SSP currency calculations.

Audit & Reporting: Maintains operational activity logs and generates printable management reports.

Role-Based Access: Provides different operational roles and interface-level permissions.

Data Export: Supports exporting production and sales records to CSV files.

Responsive UI: Includes interactive charts, mobile-friendly navigation, and dark/light themes.

Project Objective

The main objective of PETRO-STOCK is to demonstrate how digital technology can improve petroleum inventory control, production tracking, distribution coordination, financial record management, and operational reporting.

Important Note

This project currently uses browser-based local storage and sample data for demonstration purposes. It does not include a connected backend database or a verified live network synchronization service.
